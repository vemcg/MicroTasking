# MicroTasking

An alternative to "Today Is The Day" — an Android app that randomly and periodically
prompts you within a time window you set to complete a short task (5-15 min) from a list of
things you tend to procrastinate on.

## Status

Project scaffold only. No feature logic has been implemented yet — see open questions being
discussed before building features.

## Structure

- `app/` — Android application module (Kotlin + Jetpack Compose)
- `settings.gradle.kts`, `build.gradle.kts` — Gradle project config
